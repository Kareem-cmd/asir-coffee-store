# بن عسير — متجر تجريبي

واجهة عربية متجاوبة مستوحاة من الهوية المرفقة لجمعية البن بمنطقة عسير.

## تشغيل
افتح `index.html` مباشرة، أو شغّل خادم ملفات ثابتة داخل المجلد. لا توجد حزم مطلوبة أو خطوة بناء. يمكن نشر الملفات كما هي على GitHub Pages من الفرع الرئيسي.

## الوظائف
- 8 منتجات، تصفية وبحث وترتيب بالسعر.
- تفاصيل المنتجات، أوزان ودرجات طحن.
- سلة تحفظ في المتصفح وتدعم تعديل الكميات والحذف.
- باقة ضيافة ونموذج طلب تجريبي دون جمع بيانات أو دفع.
- واجهة RTL، دعم لوحة المفاتيح وتقليل الحركة، خطوط محلية وصور WebP.

## حدود التجربة
الأسماء والأسعار والخيارات والوصف التجاري أمثلة توضيحية. لا يوجد مخزون أو خادم طلبات أو دفع أو شحن فعلي. يلزم ربط نظام تجارة إلكترونية واعتماد البيانات والسياسات قبل الاستخدام التجاري.

## الصور والهوية
الأصول مقدمة من صاحب المشروع. ملفات WebP مشتقة من الشعارات والبنرات وأيقونات الأقسام وصور المنتجات المرفقة؛ صور العبوات والأكواب الإضافية مستخرجة من الصفحتين 3 و4 من دليل الهوية. الحقوق لأصحابها، ولا يمنح هذا المستودع ترخيصًا بإعادة استخدام العلامة. ملف الهوية الأصلي غير منشور.

الخط Tajawal من Google Fonts، مرخص بموجب SIL Open Font License؛ انظر `assets/OFL.txt`.
